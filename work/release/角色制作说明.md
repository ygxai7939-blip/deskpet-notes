# 桌宠便签角色制作工具包

把这个 ZIP 和角色描述或参考图交给 Codex。请它解压并读完本说明，最后交付一个通过校验的角色 ZIP。打开桌宠便签的「桌宠设置」，点击「导入角色 ZIP」或把角色 ZIP 拖进窗口。在预览中选择「安装并使用」。同一个 ID 会更新现有角色。

可直接复制[小宠物制作指令](小宠物制作指令.md)里的提示词，并把括号里的内容改成自己的角色需求。

## 新作素材

有图像生成能力时，先定稿一张透明背景的角色设定图，再以同一张图为参考生成各动作帧，保持头身比、配色、线条粗细、光照、位置和视角一致。图集中的角色保持完整四肢和带抗锯齿的透明边缘，每帧使用同一基线，左右走保持同一地面高度。逐帧预览，清理闪动、残影、意外的背景和水印。

只有代码能力时，可用 Pillow 从用户提供的透明 PNG 或 WebP 拆分、对齐和拼图。素材不足时先说明哪些动作缺少，可把一帧用于对应行做兼容占位，同时告知用户该动作只有静态图。请使用有权使用和分享的素材。

## ZIP 格式

包内只有两份文件，直接放根目录，或同放在一层目录。

- `pet.json` 是 UTF-8 JSON。必填 `id` 和 `displayName`，可填 `description` 与 `spritesheetPath`。ID 以小写英文字母开头，后续使用小写字母、数字、连字符或下划线，最长 48 字符。显示名最长 40 字，说明最长 160 字。
- 透明 RGBA 图集为 PNG 或 WebP，推荐无损 WebP。每格为 192 × 208 像素，8 列 × 9 行，总计 1536 × 1872。也接受 1536 × 2288 的图集，首版读取前 9 行。每行从第 1 列起连续放动画帧，后面的空格全透明。每行第一格要有可见素材。
- ZIP 及解压文件总量分别上限 24 MiB。普通角色 ZIP 内只放素材与清单。

```json
{
  "id": "my-pet",
  "displayName": "我的桌宠",
  "description": "由参考图制作的桌面宠物",
  "spritesheetPath": "spritesheet.webp"
}
```

| 行 | 当前动作 | 播放速度 |
|---|---|---|
| 1 | 待机 | 6 fps |
| 2 | 向右移动 | 10 fps |
| 3 | 向左移动 | 10 fps |
| 4 | 挥手或点击回应 | 8 fps |
| 5 | 跳跃 | 10 fps |
| 6 | 失落 | 3 fps |
| 7 | 等待，可表现困倦 | 10 fps |
| 8 | 忙碌，可用于拖动表现 | 6 fps |
| 9 | 查看或好奇 | 8 fps |

## 校验和打包

示例角色 ZIP 是灰色几何图案，用来验证尺寸、透明边缘和帧顺序。它可以直接导入软件。

```powershell
py -m pip install -r requirements.txt
py pack_character.py .\example.codex-pet.zip
py pack_character.py .\素材目录 .\我的角色.zip
```

最后确认预览和软件安装都能读到角色。请交付角色 ZIP，用户可直接导入。
