# 小宠物制作指令

适用于 Windows「桌宠便签」1.1.0 及以上。把这份 Markdown、角色制作工具包 ZIP 和参考图一起发给 Codex。没有参考图时，描述你想要的角色、画风和动作就可以。

## 复制给 Codex

> 请按《小宠物制作指令》给 Windows「桌宠便签」做一个可以直接导入的角色。角色叫【名字】，外形和画风是【描述，或以我上传的参考图为准】，性格是【例如慢吞吞、爱打瞌睡】，我最想看到的动作是【例如跳起来时开心地笑】。
>
> 有图像生成能力时，请先确定同一个角色的造型，再做透明动作帧。只有代码能力时，请用我给的素材对齐、拼图和打包，并告诉我哪些动作使用了静态占位。请按下文的规格制作图集和 `pet.json`，用工具包的脚本校验，修正问题后交付可下载的角色 ZIP。
>
> 需要兼容 1.1.x 时使用下面的 8 列 × 9 行格式。需要高清或摸头、提起、放下等独立动作时，按《角色制作说明》的 1.2.0 扩展格式输出。

## 制作动作素材

1. 先定一张全身参考图，明确头身比例、配色和识别特征。生成其他帧时反复引用同一张图。使用你有权使用的素材。
2. 做成透明背景。每帧统一角色大小、水平中心和脚底基线。跳跃可以改变高度，走路和待机应避免镜头、比例或地面高度抖动。保持左右朝向明确，非对称配饰和文字需要检查。
3. 按下面的行序排列。每行做 1 到 8 帧，从最左边排起。帧之间不要留空格，剩余格保持全透明。每行至少放一帧。如果只有静态素材，可放在对应行的第一格，并在交付时说明。
4. 试播一次点击回应和跳跃，检查起势和收势能否接回待机。试播循环待机和左右走，重点看末帧接首帧时是否闪动。补帧优先改善动作变化大的地方。

| 行 | 动作素材 | 软件播放速度 |
| --- | --- | --- |
| 1 | 待机，可做呼吸或眨眼 | 6 fps |
| 2 | 向右走 | 10 fps |
| 3 | 向左走 | 10 fps |
| 4 | 挥手或点击回应 | 8 fps |
| 5 | 跳跃，建议有起跳、腾空和落地 | 10 fps |
| 6 | 失落或睡觉，可做低头或闭眼 | 3 fps |
| 7 | 等待或引起注意 | 10 fps |
| 8 | 忙碌 | 6 fps |
| 9 | 查看或好奇 | 8 fps |

## 输出角色 ZIP

图集使用 **1536 × 1872 像素**，共 **8 列 × 9 行**，每格 **192 × 208 像素**。保存为带 Alpha 透明通道的 PNG 或无损 WebP。用棋盘格检查残留背景、裁切和跨格像素。

在素材目录放入图集和 UTF-8 编码的 `pet.json`。ZIP 根目录只放下面两份文件，ZIP 本身和解压后的文件总大小各不能超过 24 MiB。

```text
forest-friend.codex-pet.zip
├── pet.json
└── spritesheet.webp
```

```json
{
  "id": "forest-friend",
  "displayName": "森林小伙伴",
  "description": "一个喜欢打瞌睡的森林小伙伴",
  "spritesheetPath": "spritesheet.webp"
}
```

`id` 最长 48 字符。首字符必须是小写英文字母，之后可用小写英文字母、数字、连字符和下划线。避开 `con`、`aux`、`nul` 等 Windows 保留名。新角色使用新 ID，更新旧角色保留原 ID。`displayName` 最长 40 字，`description` 可省略，最长 160 字。

解压从软件导出的角色制作工具包，在解压目录运行以下命令。第二行打包并校验，第三行可独立核对生成后的 ZIP。把 `pet-files` 改成放置图集和清单的目录。

```powershell
py -m pip install -r .\requirements.txt
py .\pack_character.py .\pet-files .\forest-friend.codex-pet.zip
py .\pack_character.py .\forest-friend.codex-pet.zip
```

校验通过后，打开「桌宠设置 → 导入角色 ZIP」，也可以把 ZIP 拖进管理面板。先看待机预览，再点「安装并使用」。1.1.1 遇到相同 ID 时，可选「更新并使用」或「另存为新角色」，也可在「我的桌宠」里点击角色卡片切换。装好后分别观察待机、左右走和点击回应。交付时附上 ZIP、校验结果和使用静态占位的动作。
